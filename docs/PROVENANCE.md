# Evidence provenance

Upstream: https://github.com/Halleck45/OpenPronounce, MIT, commit `74bc17ea406e6f057f15eea0e70951e1931af868`. Checkout under ignored `.cache/OpenPronounce`; upstream source unchanged. Validation code imports that checkout, not a reimplementation.

The 25 everyday sentences in `validation/phrases.json` are original validation prompts, five per requested category. Their audio is **synthetic**, locally generated by macOS `say` voice `Anna (German (Germany))`. Audio is not redistributed. Voice availability/quality depends on the Mac's installed system voice; its binary is not pinned. These are smoke checks, not fluent-human or learner-pronunciation benchmarks.

15 supplementary **human** read-speech recordings are from Thorsten Müller, `Thorsten-Voice/TV-24kHz-Neutral`, the first parquet shard, pinned in `validation/dataset.lock.json`. Attribution: Thorsten Müller, Thorsten-Voice (2022), https://github.com/thorstenMueller/Thorsten-Voice . Dataset card: https://huggingface.co/datasets/Thorsten-Voice/TV-24kHz-Neutral/blob/baa97e452879d689a66464ae2b7deeae5c68ce3d/README.md . The specific HF redistribution declares **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/ . The creator's general recordings page describes CC0 originals, but this validation conservatively preserves the specific shard's CC BY attribution rather than claiming CC0 for it. Full card copy in `validation/evidence/dataset-card.md`.

Human samples are selected reproducibly by keyword and length, preserving exact transcripts and source row IDs in `validation/audio-manifest.json`. They are literary/news-style read speech, not recordings of the 25 exact prompts, and keyword matches sometimes have unrelated meanings (e.g. “Zug”). Do not treat this supplementary set as complete human coverage of everyday travel/shopping/family phrases. No expert rating or independent listening assessment was performed. One speaker, clean studio speech; no learners, children, accent diversity, noisy rooms, mobile capture, or deliberate phone-level mispronunciations.

Most WebM/Opus files are FFmpeg encodes of those source WAVs (48 kHz mono). One additional file is generated by real **Chrome for Testing MediaRecorder**, with WebAudio playback into a MediaStreamDestination. Browser version/URL and stream provenance are saved under `validation/results/chrome-*.json`. This proves ingestion of actual Chrome-produced WebM/Opus bytes, not physical microphone behavior. No website, browser server, or app deployment was created.

The default gTTS reference voice is network-dependent and not immutable. References are cached under ignored `.cache/references`; this is a remaining reproducibility limit. Source audio, model weights, and browsers remain ignored. Model snapshot revisions are pinned separately; package versions are pinned in the arm64 macOS lock. Negative controls use three seconds of digital silence and a travel recording scored against a family sentence.

## Current Prolang application

The 100 entries in `packages/deck/cards.json` are original authored text, dedicated to CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ . This includes English meanings, noun usage/plurals and bilingual examples. No external dictionary or audio corpus was copied into the deck.

Per-card references use OpenPronounce's gTTS backend (gTTS 2.5.4, MIT software), Google Translate German `de`, domain `com`. They are synthetic, network generated, cached locally, and not immutable. No separate license for Google's generated audio is asserted; Google service terms apply: https://policies.google.com/terms . Reference audio is excluded from JSON exports and is not shipped in the repository.

Button is adapted from the official shadcn-svelte manual source, with local colors/sizes and CVA in place of tailwind-variants: https://www.shadcn-svelte.com/docs/components/button . MIT notice in `docs/licenses/shadcn-svelte.txt`. Installed ts-fsrs 5.2.3 types and runtime API (`createEmptyCard`, `fsrs.next`, `generatorParameters`, `checkParameters`) informed scheduling integration.

Runtime bootstrap installs OpenPronounce from its pinned Git source, without depending on the ignored checkout. Three model revisions remain in `validation/models.lock.json`. Existing CPU validation audio/results were preserved. App QA uses separately generated gTTS references and a clearly synthetic Chrome fake microphone, not human or Android hardware recordings.

Runtime transcription now uses [Qwen3-ASR 1.7B](https://huggingface.co/Qwen/Qwen3-ASR-1.7B), Apache-2.0, revision `7278e1e70fe206f11671096ffdd38061171dd6e5`, with qwen-asr 0.0.6. It replaces the German Wav2Vec2 transcript model only. Historical validation artifacts remain unchanged. No current answer or deck lexicon is passed to Qwen. `HF_HUB_OFFLINE=1 .venv/bin/python -m scripts.check_qwen` checks the full assessment path with a synthetic German reference; it is not a learner benchmark.
